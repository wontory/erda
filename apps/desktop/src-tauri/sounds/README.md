# 타이머 효과음

`generate.mjs`가 합성한다. 외부 음원을 쓰지 않아 라이선스 제약이 없다.

카운트다운과 종료음은 D장조 한 곡처럼 이어진다. 음색은 금속 관 윈드차임(자유단 막대 배음 + 맥놀이)이고
긴 홀 잔향(프리딜레이)과 좌우 핑퐁 메아리가 걸려 공간이 넓게 울린다.

| 파일         | 쓰임                                                                                 |
| ------------ | ------------------------------------------------------------------------------------ |
| `tick.wav`   | HUD 카운트다운 동안 매초. 짧게 울리는 차임 한 음(A5)                                 |
| `finish.wav` | 종료. Dmaj9 차임이 부드럽게 겹쳐 피어나고 같은 화음의 패드가 받쳐 한 덩어리로 울린다 |

```sh
node apps/desktop/src-tauri/sounds/generate.mjs                  # 이 폴더에 다시 만든다
OUT=/tmp/s node apps/desktop/src-tauri/sounds/generate.mjs       # 다른 곳에 만들어 들어 보기
```

실행 파일에 `include_bytes!`로 들어간다(`src/sound.rs`).
